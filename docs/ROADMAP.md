## Pharmacy Inventory Best Practices
1. **FIFO** (First In, First Out) - always sell oldest stock first
2. **Par levels** - set minimum stock levels for each item
3. **ABC analysis** - categorize by value (A=high, B=medium, C=low)
4. **Cycle counting** - count a portion of inventory daily instead of full count
